# Where Light Dies

Team Milestone 1 – Playable Core (~40%)

## Supported Operating System
This playable build runs on:
Windows lab machines
## How to Run the Game

- Extract the ZIP file.
- Open the folder.
- Double-click `WhereLightDies.exe.`

- Keep all files in the same folder.
No IDE (Godot) is required.

## Game Overview

- This milestone demonstrates the core navigation system of EndlessFog.
- Players can move through a maze environment with proper collision detection and camera support.

## Controls

Movement:

- W / A / S / D
- Arrow Keys
